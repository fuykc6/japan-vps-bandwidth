## 日本大带宽VPS，带宽要多大才算“大”

先说标准：100Mbps 以下，这篇文章里不把它当大带宽。对照目前真实在售的方案，大致分三档：100M-500M 属于中端（IJC 100M、V5 Server 200M、JUSTG 500M），1Gbps 是主流“大带宽”门槛（Evoxt、V.PS 都给到 1Gbps），2.5Gbps 以上算高端（搬瓦工大阪软银起步就是 2.5Gbps）。

比带宽数字更值得注意的是带宽和流量的绑定关系。大带宽套餐普遍配有限流量，而且带宽越大、流量给得越克制：Evoxt 最低配 1Gbps 带宽只配 250G/月流量，均摊下来每天不到 9G；JUSTG 的 500M 带宽配 500G/月；V5 的 200M 配 800G/月；搬瓦工 2.5Gbps 配 2T/月，在同类里已经算大方。Locvps 的东京机房干脆拆成两类卖——小带宽不限流量、大带宽限制流量，入口出口双向计算。

所以挑选顺序应该是：先估算自己每月的真实流量，再回头选带宽。纯建站、跑轻量应用，100M 加宽裕流量可能比 1Gbps 配 250G 更实用；要做下载或流媒体，带宽和流量两项都得往上调。
